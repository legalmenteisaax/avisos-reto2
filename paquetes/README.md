# Paquetes de cambios

Cada carpeta es un cambio listo para que un integrante lo suba desde su cuenta.

```
paquetes/2026-11-22-ejemplo/
├── paquete.json   # para quién es, título, resumen, mensaje del commit y archivos
├── guia.md        # explicación sencilla para entenderlo y sustentarlo
└── archivos/      # los archivos con la misma ruta que tienen en el repo del equipo
```

Al subir una carpeta nueva, el bot la manda por Telegram con un zip y las instrucciones.
